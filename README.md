# Placement Prep

A small offline web app with two parts:

- **Playbook** (`playbook.html`): the daily tracker. Today's problems, ticks, XP, ranks, badges, and lessons for C++, Striver A2Z, Core CS, cyber, AWS and AI. Five themes.
- **Roadmap** (`roadmap.html`): the plan from November 2026 to June 2028, week by week, with milestones, the intensive track and the off-campus system.

`index.html` is the home screen. Progress is saved in the browser (localStorage); back it up from the playbook, Part 09.

## Run it

Open `index.html` in a browser, or host the folder on any static host.

**GitHub Pages:** Settings → Pages → Source: "Deploy from a branch" → pick this branch and `/ (root)` → Save.
The app appears at `https://<username>.github.io/<repository>/` after a minute or two.

**Install on a phone:** open that address in Chrome → menu → "Add to Home screen". It then opens like an app and works offline.
